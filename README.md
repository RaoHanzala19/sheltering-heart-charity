# 🤲 Sheltering Heart: Orphanage & Charity Website

A multi-page charity website for an orphanage, where visitors can learn about the cause, choose a donation type and check whether Zakat is due with a built-in calculator.

Built with **HTML, CSS, JavaScript, Bootstrap and jQuery** as an Aptech e-project.

> 📸 _Screenshots coming soon_

---

## ✨ Features

- 🏠 **Home page** with causes: education needs, orphan sponsorship, helping children in need
- 🧮 **Zakat calculator**: enter cash, gold, silver, investments, money owed and stock, minus debts and expenses, and it tells you if your net assets reach the nisab
- 💝 **Donation options**: Zakat, Sadaqah, Fidyah, Health, Back to School and more
- 🛒 **Donation box (cart)** with a checkout flow for card, PayPal and bank transfer _(front-end demo, no real payments)_
- 🖼️ **Gallery**, **Our Mission**, **About** and **Contact** pages
- 📱 **Responsive** layout with Bootstrap, plus sliders and animations

## 🛠️ Tech Stack

HTML5 · CSS3 · JavaScript · Bootstrap · jQuery · Owl Carousel
